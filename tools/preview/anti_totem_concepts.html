Anti Totem Block Concepts

An admin-only block that keeps Shatter Totems and BSP machines out of an area, for spawn, hubs and event arenas. Only admins can place, set up or break it. Three looks for the block and three layouts for its settings screen. Drag the 3D views to turn them. Nothing here is in the mod yet.

1. The block

2. The protected zone

The zone is a box around the block. Admins holding the block's item, or looking at the block, would see its outline like this; players never see it. Change the size to see how it sits around the block.

3. The settings screen

What an admin sees on right-click. All three set the same two things: how big the zone is, and what is kept out of it.

A. Simple Panel

One screen: three sliders for the size (the same distance each way from the block) and a tick box for each kind of thing to block. Quickest to use, but the zone is always centred on the block.

B. Box Editor

Six distances, one for each direction, so the zone can be off-centre (for example mostly above ground, or along one side of a wall), with a map of the zone from above. Blocked things are grouped as switches.

C. Rule List

Two tabs. Zone has the six distances. Rules lists every BSP block and machine by name, so each one can be allowed or blocked on its own, with a switch per group to set them all. Most control, and new machines appear in the list by themselves.

What the block does, in all three

Totems

  1. Placing a totem in the zone is refused with a message.
  2. Dropping one puts it straight back in the inventory.
  3. A totem carried in when its owner dies or logs out is placed at the nearest spot outside the zone.
  4. Storing is already impossible everywhere: totems cannot go in containers.

Machines and blocks

  1. Blocked BSP blocks cannot be placed in the zone.
  2. Ones that were already there keep working until an admin removes them.
  3. Admins are never restricted.

The block itself

  1. Creative tab only, no recipe.
  2. Cannot be mined, pushed or blown up; only an admin in creative can remove it.
  3. Zones can overlap; the strictest rule wins.
