1. The chest: three sci-fi lids

2. The shielding set, joined

The same set is built three ways. A block's edge keeps its border and rivets only where the next block is not the same kind. Panels join panels and windows join windows. A panel next to a window or the door keeps its border, so the opening is framed. Where a group turns an inside corner, the border closes the corner as well. Untick "Window frame in lead" to see B's window in its own pale frame.

3. Pick, with defaults

  1. The lid. The default is 1, Rail Frame: a raised rail runs round the top with cut corners, a green light line runs just inside it, and the radiation plate sits sunk in the middle. It reads as sci-fi from every side without changing the box's shape. With 2, Armoured Spine, the lid gets a raised spine from front to back with vents and two lights, which gives the strongest machine look. With 3, Seal Ring, angled brackets clamp the four corners and the plate sits in a raised ring like a hatch seal.
  2. The window frame. The default is that the window frame is lead, so a window sits in a lead wall as part of the same set. Otherwise the window keeps B's pale tile frame, which stands out from the lead panels.
  3. The gauge on a double chest. The default is that a double chest has one gauge, on the top-right square of the front as you face it, and both halves share its reading. Otherwise each half keeps its own gauge, so a double chest shows two.
  4. How the joining is built. The default is that BSP-Core draws the joined blocks itself, looking at all eight neighbours on each face, so inside corners close and nothing new is needed in the pack. Otherwise the blocks use Fusion, the connected-texture library already in the pack for Connected Glass. That means less code, but BSP-Core then needs Fusion installed.
