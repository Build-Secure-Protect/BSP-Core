Vault Merge Concepts

How Coin Vault blocks could look once they join into one vault. Three options, all shown at the size set below, from a single block up to 3 x 3 x 3. Drag a view to turn it. Nothing here is in the mod yet.

What stays the same

Storage, access, upgrades and lockpicking do not change: this is only the look. The single block keeps the Classic Safe. A group that is not a full box (an L shape, a missing corner) would be drawn as the largest full box plus separate safes for the leftover blocks. The door is drawn on the side the vault blocks face.
