Plasma Injector Looks

Three designs for the block that stands against a machine and feeds it Wave Plasma. Each shows the machine as the dark cube on the left, so you can see which end grips it and which end takes the cable. Drag to turn. The controls drive every view: how much plasma arrives, and whether any arrives at all.

1. The block

All three keep the same footprint as today (a column of 12 x 12 inside the block, 16 long) so the shapes and the six facings stay as built. The machine end is on the left in every view.
