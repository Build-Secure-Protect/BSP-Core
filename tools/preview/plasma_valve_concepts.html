Plasma Valve Concepts

A block that sits in a cable run and limits what passes, and shuts when a lever on it or a redstone signal says so. It does not weaken powers like a repeater and it does not start a fresh run. Three looks for the block, three looks for its screen, and the rules. Drag any 3D view to turn it. The controls below drive every view at once.

1. The block

All three are cable-sized along one axis, wrenchable like the repeater, and fit between two cables. A vanilla lever is shown on each so you can see where it would sit. The same plasma runs in and out at the set limit.

2. The screen

Right-click opens it (Machines access on the totem, like the charger). Each shows the limit, what is actually passing, and why the valve is shut if it is.

UI-1. Slider

One horizontal slider with ticks, nudge buttons for exact numbers, a flow bar underneath. Plainest to read and to use.

UI-2. Gauge

A vertical tank-style gauge you drag, with preset buttons for quarters. Reads like the base's tank.

UI-3. Dial

A round dial you drag around, matching the gauge on block A. Looks the part, slower for exact numbers.

3. Rules

RuleProposed
What it limitsThe pressure that may pass, in the same units as the cable labels (mB/t). Slider 0 to 2000 in steps of 10. Cables after the valve show the limited figure.
ShutA lever on any face of the valve, or any redstone signal into it, shuts it. Shut means 0 passes: the run beyond goes dark and the base beyond drains like a cut cable.
PowersPass through unchanged, every level. The valve counts as one cable of reach and does not start a fresh run.
DirectionNone. It lies along an axis (wrench turns it). The interface decides which way plasma moves, as with cables.
Sharing at the interfaceEach run gets an equal share of the supply; a run that needs less leaves the rest for the others. This on its own fixes the screenshot. Valves then shape it further.
Interface viewThe valve shows in the 3D view with its limit and OPEN or SHUT. Jade shows the same line as a cable.
