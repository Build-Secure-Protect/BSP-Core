Herald Discord Concepts

Mock-up set 1 for the Discord steal warnings. Section 1 is the look of the messages in Discord: the warning DM, the outcome DM, the one public line in #totem-alerts, and the bot's answer to /link. Section 2 is Herald's card in the totem screen, where the player links their Discord. Each look follows the 17 decisions: a DM to the owner only, one line in the channel naming only the server, sent when the game warns the owner (after the thief's Shroud), and nothing in game or Discord shows anyone's Discord name or number.

1. The messages in Discord

The same steal in every look: Steve is stealing Mrgregles's totem at 120 64 -340 on Frostwarf, 45 seconds left; then the steal fails because Steve walked away. Each look also shows how the warning reads as a phone notification, since that is where an offline player sees it first. Every look puts the key sentence in the message text itself, so the notification reads well even when a card follows.

A short text line, then a card with a red edge and four labelled boxes (server, where, thief, time left). The outcome is a second card, green when saved and red when lost. The channel line is a small grey card with the server's name only.

2. Herald in the totem screen

Herald sits beside Sentinel off Alarm, at tier II (decision 2). The screen is drawn at its real size, 326 by 261 game pixels, scaled up. Choose a state to see how each placement handles it: not linked, code shown after the player presses Link, linked, and a server with no Discord. In every placement the code also goes to chat as a line the player can click to copy, because they have to type it in Discord.

[Herald] Your Discord link code is K7PQ2M. In the BSP Discord, type /link K7PQ2M within 10 minutes. [Copy]

A. Inside the card, under Buy

A Discord line and a small LINK button sit right under the Buy button, in the space the red "blocked" line uses on other upgrades. The code replaces that line while it is valid.

B. A Discord box in place of the tier box

While Herald is the chosen upgrade, the dark box under the card (where "Raise to tier III" usually is) becomes a Discord box with the status and a big code. Picking any other upgrade brings the tier box back.

C. A Discord chip in the top bar

A small DISCORD chip beside the tabs shows the link on every page of the totem screen. Clicking it opens a small card over the tree with the code, the time left and Unlink. Herald's own card only says when a link is needed.
