Holo Grid

The window a player opens from their inventory to lay out their machines and their map. Each concept below shows three moments: drawing a box and picking what goes in it, the finished page in use, and saving presets or pinning a box to the game screen. The grids are live. Drag on an empty spot to draw a box, drag a selected box to move it, drag its corner to resize it, and right-click a box to delete it. Page tabs, keys and list rows all respond to clicks.

  • Read-only or operable. Use the switch below to stand inside a Remote Control Transmitter's range. Machine boxes then show OPERATE, and clicking one opens the machine's own screen. Outside the range they show the eye, which means read-only.
  • The map box is JourneyMap's full map, the screen the J key opens, with its own toolbar. You can drag and zoom it whenever the Holo Grid is open. The map here is a stand-in drawing.
  • Real time. The bars move as they would on the same server. The Nether smelter is on survival-2 in an unloaded chunk, so it shows "asleep" and its last reading.
  • All names, machines and numbers are examples.
Hover a box in a finished page to see its pin key.

A. Blueprint Sheet

The grid fills the whole window. Page tabs sit along the top like folder tabs, with a + key to add a page. The keys sit on the right of that strip: BUILD (DONE while building) and PRESETS together, then a gap, then POPOUT and PIN. While building, the grid shows its corner dots and a strip at the bottom holds the COLUMNS and ROWS steppers. A new box opens a floating ASSIGN card beside it, with MACHINES, MAP and ALL TAGS chips and one row per tagged machine showing its lamp, its name and its server. Presets open as a dialog with a small picture of each page. PIN opens a dialog with a small game screen where you click the corner the box goes to.

B. Side Dock

Every key sits in one column on the left, grouped like the bank screens: the PAGES list (number, name, how many boxes), then GRID with its two steppers, then MODE with BUILD and VIEW. PRESETS, POPOUT and PIN A BOX sit apart at the bottom. Column numbers run along the top like a spreadsheet. When you draw a box, the dock turns into the assign list, with each machine's type under its name, MAP and ALL TAGS keys, and BACK and DELETE. Presets show as four large cards with a picture of the first page and smaller pictures of the rest.

C. Holo Table

A steel table with corner screws. The grid sits in a sunken bezel. Nine round lit keys along the top choose the page, with + on the free ones. A lever on the left flips between BUILD and VIEW, and two knurled knobs set the columns and rows. Presets are cartridges in a rack on the right, each showing its first page on the label. SAVE, POPOUT and PIN keys sit under the rack. A drawer along the bottom holds one tile per thing you can show: the map, all tags, then each tagged machine with its icon and lamp. Click a tile to fill the new box. Pinning shows the game screen with four corner sockets and a size knob.

What every concept shares

PartBehaviour
Grid sizeEach page has its own grid, from 4 to 32 columns and 3 to 24 rows, starting at 12 by 8. Shrinking a grid trims the boxes that no longer fit.
BoxesDrag across cells to draw a box. Boxes never overlap: one drawn on top of another shows red and is not kept. Drag a selected box to move it, drag its corner to resize it, and right-click it to delete it.
Assign listYour tagged machines (a machine already on this page shows dimmed), the Map, and All tags.
PagesUp to 9. Click to switch. "Next page", "Previous page" and "Page 1" to "Page 9" start unbound in Controls, and they also work in game to change the popout's page.
PresetsUp to 10, saved on the server so they follow you across the network. Each one keeps every page. Loading one asks before it replaces your pages, and a reset never removes them.
PinOne box from any page goes to a corner of the game screen, small or medium. A key you set shows and hides it. It is hidden with F1 and while a screen is open.
