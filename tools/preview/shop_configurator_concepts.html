Shop Configurator Concepts

Three ways an admin builds and runs shops, all opened with /bsp shop. The configurator is an admin tool, so all three sit in the Holo HUD admin look (dark, violet) beside the Admin Rack panel; the shops players see get their own skins. What differs is how the admin works: a desk of lists and tabs, a workbench where you edit the live shop by clicking its slots, or a guided deck of steps. Switch the screen to see each concept do the same job.

Decided (owner, 2026-10-11)

B, Workbench, built in the Cash Machine skin like the bank rather than the Holo HUD admin look shown here. The item in hand goes to the next free slot with one key, the browser covers everything else. The admin key under a live shop is seen by admins and moderators, moderators read-only. A and C are not chosen.

ScreenHas
Shop listEvery shop with its kind (shop, sub-section, rotating, special offer), item count, Shopping Network flag, where it is assigned (posts, stalls, Easy NPCs), open or closed now; New shop, Duplicate, Delete; search.
Shop settingsName, parent (for a sub-section), kind, Shopping Network on or off, style preset, pages; per item: buy price and sell price each in pieces or a coin tier (either side off), global stock and per-player stock with a restock countdown, instant buy, hidden; rotating: pool, display slots, interval; special offer: discount percent and end time.
Item browserThe item in hand, or every item in the modpack: a search box, grouped by creative tab, mod id shown; click to add to the selected slot.
Layout and styleThree built-in presets (Cash Machine, Passbook, Market Board) and the admin's saved ones; the palette (bezel, screen, text, keys), rows, where the keys sit, the grid shape; Save as preset.
Preview and test buyThe real shop screen in test mode: buys and sells report what would be charged and given, nothing moves and nothing is logged; a Test as picker for stock limits.

3. Decisions

  1. Concept: A Desk, B Workbench, or C Deck. They can mix: a Deck for new shops that lands on the Desk, for example.
  2. Admin look: Holo HUD admin (shown, matches the Admin Rack panel), or the Cash Machine skin like the bank.
  3. Adding items: the item in hand always goes to the next free slot with one key, the browser for everything else (default), or the browser only.
  4. Who sees the admin panel key under a shop: admins only (default), or admins and moderators (moderators read-only).
