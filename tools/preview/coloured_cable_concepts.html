Coloured Cable Concepts

Two things: cables in every dye colour so runs can be kept apart, and a wrench that sets what each end of a cable does. Drag any 3D view to turn it. The names drop the word Core from here on: Tetrium Plasma Cable, Magnatite Plasma Cable, and so on.

1. Coloured cables

Sixteen colours, three kinds

Magnatite, Illyrium and Charged Illyrium cables come in all sixteen dye colours; the glass takes the dye and the rails stay dark. Tetrium stays plain. Front row Magnatite, middle Illyrium, back Charged Illyrium, with the plain cable of each kind at the left end.

Eight cables of one kind round a dye. Any colour can be dyed again the same way, so a wrong colour is not wasted. Reach and throughput are the kind's; colour changes nothing but who it joins.

Who joins whom

A blue run and a red run cross without joining. A coloured cable joins only cables of its own colour; a plain cable joins only plain cables. Every cable still joins machines: interfaces, bases, chargers, valves and repeaters take any colour.

2. Wrench-set cable ends

Right-click an end of a cable with the wrench to change what that end does, the way Mekanism pipes are set side by side. Each click steps the end on: Normal, Output (plasma may only leave the cable this way), Input (may only enter this way), Off (not joined), then back to Normal. Where two different colours meet, the first click Links them. Sneak-click puts an end back to Normal. The three views show the same cable with all five ends set, in three looks.

3. The wrench in use

Click an end of the cable below as if with the wrench. The line under the view is what the game would show over the crosshair while the wrench is held. The right end meets a red cable, so its first click links the colours.

Sneak + click resets an end to Normal.

4. Rules

RuleProposed
ColoursAll sixteen dyes, for Magnatite, Illyrium and Charged Illyrium: 48 new cables. Tetrium stays plain.
Recipe8 cables of one kind + 1 dye = 8 of that colour. Works on already coloured cables too.
JoiningSame colour only; plain to plain only. Machines take any colour. The interface view shows each run in its colour.
EndsSet per end with the wrench: Normal, Output, Input, Off, and Link for a forced join across colours. Stored in the cable, kept when the cable is picked up with the wrench, lost when broken.
Output and InputThe interface's search only moves plasma out of an Output end and into an Input end. An Off end is a wall. So one Output end at a base keeps a loop from feeding back, and an Input end on a shared trunk stops a run drawing from the wrong side.
ShownThe chosen look draws on the cable itself; the wrench shows a line over the crosshair with the end you are pointing at and its setting.
