Shatter Coin Concepts

Three directions for the Shatter Coin Factory, its coins and its speed upgrades. Every factory is built from Minecraft-scale cuboids inside one block, and every coin and upgrade is a 16×16 pixel sprite shown extruded the way the game draws held items. Drag a factory to rotate it.

All coins share the silver outer ring and differ only by inner colour and emblem style per concept. The press animation here loops in seconds so it can be judged; in game one strike plays as each coin finishes and the machine idles between strikes. Installed upgrades light the sockets on the casing. How much each upgrade shortens the press time is still to be decided.
