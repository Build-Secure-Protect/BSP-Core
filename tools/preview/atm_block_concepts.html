Bank ATM Looks

Three designs for the Bank block: two blocks tall, one wide, placed by admins, right-click opens the banking screen. The chosen screen skin is the Cash Machine (green phosphor screen, beige keys), so every look carries a real glowing screen on the top block and keeps the key column idea beside it. The plain grey cube at the side is one block, for scale. Drag to turn; the views idle slowly.

Decided (owner, 2026-10-11)

B, Vault Pillar. Gives off light at night like a real machine (level 7). The idle screen shows SHATTER BANK and the server name. A key beep on opening, a cash-tray clunk on a withdrawal. A and C are not chosen.

3. Decisions

  1. Look: A Street Machine, B Vault Pillar, or C Teller Window.
  2. Light: the block gives off light at night like a machine (level 7, default), or only the renderer glows with no light level.
  3. Idle screen: shows "SHATTER BANK" and the server name when nobody is using it (default), or stays dark until opened.
  4. Sound: a short key beep when the screen opens and a cash-tray clunk on a withdrawal (default), or silent.
