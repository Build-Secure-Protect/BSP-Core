Setting a player's score

Three ways for the admin panel to show and set scores. In every option a score set by hand is stored as an adjustment on top of the points the player's totems give, so it keeps moving when they take, lose or upgrade a totem. Click players, type a score and press SET to try each one. The players and numbers are examples.

A. On the player's page

The Players tab keeps its layout. Under the player's name the score line gets a number box with SET and CLEAR, and a small line beneath says how the score is made up. Players with an adjustment get a violet star in the list.

B. A Scores tab

A fifth tab lists every player in one table: totems, the points those totems give, the adjustment, and the score. Pick a row, type the score and press SET. This is the quickest way to fix many players in one sitting, and a player whose points look too high for their totem count stands out.

C. A Set Score window

The Players tab gets a third button, SET SCORE, beside TP and RESET TOTEMS. It opens a small window over the panel with the breakdown, steps of -10, -1, +1 and +10, a box for the exact number, and an optional reason that goes in the server log.
