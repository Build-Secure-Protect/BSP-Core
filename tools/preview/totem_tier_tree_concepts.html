Totem Tier Tree Concepts

A longer upgrade path for the Shatter Totem. The totem itself now has five tiers, each paid for with a specific Shatter Coin; upgrades unlock each other along paths; and every price names the exact coin and how many. All numbers are a first proposal for you to change.

How the proposed system works

  1. The totem has five tiers, I to V. Each tier has its own coin: Copper, Gold, Diamond, Netherite, Illyrium. Raising the totem a tier costs coins of the tier you are leaving, plus XP levels.
  2. Upgrades appear at a tier. Only four are available at Tier I. The rest appear at Tiers II, III and IV.
  3. Upgrades unlock each other. Each sits on a path. The next one on the path opens when the one before it reaches level 2 and the totem is at the right tier.
  4. Each tier adds two levels. An upgrade can gain two levels per totem tier from the tier it appears at, so a Tier I upgrade goes to level 10 and a Tier IV upgrade to level 4.
  5. Every level costs that tier's coin and XP. Levels bought at Tier II cost Gold coins, at Tier III Diamond coins, and so on. Carried upgrades lean on XP; Base and Raid upgrades lean on coins.

A. Tier Rings

The totem in the centre and one ring per tier. Each path is a straight spoke, so nothing overlaps; an upgrade sits on the ring of the tier it appears at. Locked rings are dim. Closest to the tree you picked before, and shows the whole system at once, but names only appear in the side panel.

B. Tier Lanes

A left-to-right tree. Columns are the totem's tiers, rows are the five paths, and each node shows its name and levels. Locked tiers are hatched. The easiest to read and to follow a path along; less of a centrepiece than the rings.

C. Branch Trees

One branch at a time on a tab (Carried, Base, Raid), growing downward through tier bands. Nodes are large, with the name, level bar and next price on the node itself. The most detail per upgrade, but you only see one branch at once.
